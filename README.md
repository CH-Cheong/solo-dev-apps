# solo-dev-apps
직접 1인 개발한 시니어 무료 교육용 앱 모음

-----------------------------------------------
[추억 열쇠 찾기]

-그림자와 같은 모양의 열쇠를 찾아 문을 열면, 옛날 동네의 장면과 이야기가 나오는 어르신 돌봄 수업용 교육 콘텐츠입니다.

-장소 고르기: 만물상회, 옛날 학교, 할머니 집
-열쇠 3개를 찾으면 문이 열리고, 종소리와 함께 옛날 장면 그림과 이야기가 나옵니다.
-이야기 끝의 질문으로 어르신들과 옛 추억을 나눌 수 있습니다.
-난이도 1~5단계, 점수·시간제한 없음
-인터넷 없이 동작하며, 개인정보를 수집하지 않습니다.

[설치]
-오른쪽 Releases에서 최신 .apk 파일을 휴대폰으로 내려받습니다.
-파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 설치를 묻는 창이 나오면 허용합니다.
-안드로이드 4.4 이상에서 사용할 수 있습니다.

[이용 안내]
-개인과 기관(요양시설, 주간보호센터 등) 모두 수업과 활동에 무료로 사용할 수 있습니다.
-앱과 그림, 음성을 수정·재배포·판매하려면 개발자의 허락이 필요합니다.
-교육용 콘텐츠이며 질병의 진단·치료·예방 등 의료 목적으로 사용하지 않습니다.

-----------------------------------------------
